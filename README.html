Smart-Map

Compatible with QGIS 3.10+ and QGIS 4 (tested on QGIS 4.2 / Windows 11).

Open-source QGIS plugin for soil attribute mapping with Ordinary Kriging, Support Vector Machine (SVM) interpolation, and management zones.

Install from ZIP

  1. Download Smart_Map.zip from the GitHub Releases page.
  2. In QGIS open Plugins → Manage and Install Plugins → Install from ZIP.
  3. Select Smart_Map.zip, install, and enable Smart-Map.

On first load, missing Python packages (for example scikit-learn) are installed automatically into the writable QGIS user profile.

Português

Compatível com QGIS 3.10+ e QGIS 4.

  1. Baixe Smart_Map.zip em Releases.
  2. No QGIS: Plugins → Gerenciar e Instalar Complementos → Instalar a partir de ZIP.
  3. Selecione o ZIP, instale e ative o Smart-Map.
