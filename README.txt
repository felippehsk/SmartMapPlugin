Smart-Map
=========

QGIS 3.10+ and QGIS 4 plugin for Ordinary Kriging, SVM interpolation,
and management zone mapping.

Install
-------
1. Download Smart_Map.zip from:
   https://github.com/felippehsk/SmartMapPlugin/releases
2. In QGIS: Plugins -> Manage and Install Plugins -> Install from ZIP
3. Select Smart_Map.zip and enable Smart-Map

On first load, missing Python packages such as scikit-learn are installed
automatically into the QGIS user profile.
